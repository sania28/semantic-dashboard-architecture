# RAB Tech Academy - Task 03

## Semantic HTML5 & Accessible Component Architecture

This project is developed as part of the RAB Tech Academy Full Stack Web Development Internship.

The project focuses on building the structural foundation of an enterprise dashboard using semantic HTML5, accessible form controls, structured tables, navigation, and accessible dialog components.

## Features

- Semantic HTML5 page structure
- Accessible header and navigation
- Dashboard sidebar navigation
- Structured main content sections
- Accessible data tables
- Accessible user management form
- Proper labels and form validation attributes
- Fieldset and legend for grouped form controls
- Accessible dialog component
- Responsive layout
- Keyboard-friendly focus styles
- WCAG 2.1 accessibility principles

## Accessibility Features

The implementation includes:

- Descriptive page titles
- Accessible navigation labels
- Proper heading hierarchy
- Table captions and column scopes
- Explicit form labels
- Required form fields
- Input type validation
- Autocomplete attributes
- ARIA labels where appropriate
- Visible keyboard focus indicators
- Responsive layout for different screen sizes
